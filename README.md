# svdump
This program dumps the S3 Sonic Vibes' DSP to assist in reverse engineering and emulation for 86Box

## Usage:
svdump [enhanced-base-hex] [outprefix]

e.g. svdump B400 svdsp

## Instructions:
Install drivers in Win9X and obtain the 16bit I/O base hex from the device manager

Boot into a clean DOS boot disk without any drivers loaded and run the program

Provide the dumps through an issue or by Discord DM (@NexGenDriven) or in the 86Box server in #86box-dev channel with a ping
